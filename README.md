# CodeAlpha_Disease-Prediction-from-Medical-Data
Disease Prediction from Medical Data is a machine learning project that predicts disease risk from clinical data. It uses three UCI datasets (heart disease, diabetes, breast cancer) and compares Logistic Regression, SVM, Random Forest and XGBoost. It reaches about 0.88, 0.81 and 0.99 ROC-AUC respectively, and it is for research and education only.
